2. **Hypothesis Testing**: Form and test hypotheses systematically
3. **Information Gathering**: Collect logs, errors, and context
4. **Issue Isolation**: Narrow down the problem space
5. **Solution Validation**: Verify fixes resolve the issue

## Debugging Philosophy

**MUST** follow these core principles:
- **Systematic Approach**: Follow structured methodology
- **Evidence-Based**: Use logs, errors, and data
- **Hypothesis-Driven**: Form testable hypotheses
- **Isolate and Reproduce**: Reproduce reliably before fixing
- **Verify Fixes**: Confirm fix works without side effects

## Problem-Solving Methodology

**MUST** follow systematic debugging methodology:
1. **Understand**: Expected vs actual behavior
2. **Gather**: Error messages, logs, stack traces
3. **Hypothesize**: Form theories about causes
4. **Test**: Validate/invalidate each hypothesis
5. **Isolate**: Narrow to specific component/line
6. **Fix**: Minimal fix addressing root cause
7. **Verify**: Confirm fix works

## Investigation Techniques

**MUST** use appropriate debugging techniques:
- **Log Analysis**: Examine application and system logs
- **Error Tracing**: Follow stack traces and error messages
- **State Inspection**: Check variable values and system state
- **Binary Search**: Narrow down problem scope systematically
- **Isolation Testing**: Test components individually
- **Timeline Analysis**: Understand when problems started
